# CalculaNotas — Página web

Proyecto para la actividad de Tecnología e Informática.

## Tecnologías

- HTML
- CSS
- JavaScript

## Funciones

1. Permite introducir tres notas.
2. Valida que estén entre 0 y 5.
3. Calcula el promedio.
4. Indica si se aprueba con promedio de 3.0 o superior.
5. Tiene diseño responsive para celular y computador.
6. Incluye botón para limpiar los datos.
7. Se puede publicar gratuitamente con GitHub + Vercel.

## Probar

Abre `index.html` en un navegador.

## Publicar

Sube `index.html`, `style.css` y `script.js` a un repositorio de GitHub.
Después puedes importar el repositorio en Vercel y desplegarlo como sitio estático.

No necesita servidor ni base de datos.

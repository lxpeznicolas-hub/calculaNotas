¿Cómo funciona CalculaNotas?

CalculaNotas es una herramienta que permite calcular fácilmente el promedio de tres notas académicas.

📝 Ingresa tus notas

Escribe tres calificaciones entre 0 y 5.

🧮 Calcula el promedio

La página suma las tres notas y las divide entre 3.

✅ Revisa el resultado

Si el promedio es 3.0 o más, estás aprobado.

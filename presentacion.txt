GUION PARA LA SUSTENTACIÓN

Proyecto: CalculaNotas

1. ¿Qué hace?
Es una página web que permite calcular el promedio de tres notas y saber si el estudiante aprueba.

2. ¿Qué tecnologías utilicé?
HTML para la estructura, CSS para el diseño y JavaScript para la lógica y la interacción.

3. ¿Cómo funciona?
El usuario escribe tres notas entre 0 y 5 y pulsa "Calcular promedio".

4. ¿Cómo se calcula?
El programa suma las tres notas y divide el resultado entre tres:
Promedio = (Nota 1 + Nota 2 + Nota 3) / 3

5. ¿Cómo se valida?
JavaScript verifica que las tres notas estén completas y que ninguna sea menor que 0 o mayor que 5.

6. ¿Cómo se sabe si aprueba?
Si el promedio es mayor o igual a 3.0 aparece APROBADO. Si es menor a 3.0 aparece NO APROBADO.

7. ¿Qué hace CSS?
Da color, tamaños, espacios, tarjetas, botones y adapta la página a celulares.

8. ¿Qué hace JavaScript?
Lee los campos, valida los datos, realiza el cálculo y modifica el resultado en pantalla sin recargar la página.

9. ¿Cómo la publiqué?
El proyecto puede subirse a GitHub y después desplegarse con Vercel como una página web pública.

IMPORTANTE:
Debo poder explicar cada parte del código porque el profesor puede preguntarme cómo funciona.
